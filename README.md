# portfolio_optimizer

A browser-only Black–Litterman portfolio optimizer designed as a lightweight NISA research tool.

No Python, C#, backend server, build step, package manager, or external JavaScript library is required.

## Live app

GitHub Pages deploys the static app from this repository.

## Use

1. Load a CSV of adjusted prices, or click **サンプル**.
2. Choose the maximum allocation allowed for one asset.
3. Add relative views such as “S&P 500 will outperform All Country by 2% per year” and set confidence.
4. Click **最適化する**.

The model parameters are intentionally hidden from the main interface to keep the app compact. The current internal defaults are:

- risk aversion `δ = 2.5`
- `τ = 0.05`
- mean-variance `λ = 3.0`
- risk-free rate `1%`
- annualization `252` trading days
- equal-weight equilibrium market proxy

## CSV format

The first column is treated as a date/label and all remaining columns as positive asset prices.

```csv
Date,All Country,S&P 500,NASDAQ 100,TOPIX,Gold
2026-01-05,100.0,100.0,100.0,100.0,100.0
2026-01-06,100.2,100.4,100.7,99.9,100.1
2026-01-07,100.1,100.5,100.4,100.3,100.6
```

The parser is intentionally simple; quoted fields containing commas are not supported.

## Black–Litterman model

Daily log returns are used to estimate the annualized covariance matrix `Σ`.

The equilibrium excess return is

```text
Π = δ Σ w_mkt
```

where the current UI uses an equal-weight `w_mkt`.

For views `P`, `Q`, and uncertainty matrix `Ω`, the posterior mean is

```text
μ_BL = [ (τΣ)^-1 + P' Ω^-1 P ]^-1
       [ (τΣ)^-1 Π + P' Ω^-1 Q ]
```

Each UI view has the form

```text
Asset A - Asset B = q
```

and the confidence slider maps to diagonal uncertainty by

```text
Ω_i = τ (p_i' Σ p_i) (1 - c_i) / c_i
```

## Portfolio optimization

The selected portfolio solves

```text
maximize  μ_BL' w - (λ / 2) w' Σ w

subject to
  sum(w) = 1
  0 <= w_i <= max_weight
```

using projected gradient ascent with projection onto the capped probability simplex.

## Efficient frontier

The displayed frontier is generated by solving the same constrained mean-variance problem across a log-spaced range of risk-aversion / variance-penalty coefficients. This traces the long-only, capped-weight efficient set under the Black–Litterman posterior return vector and estimated covariance matrix.

## Future-return range

The forecast chart normalizes the current portfolio value to 100 and projects 1–10 years using the optimized portfolio's annualized Black–Litterman expected return `μ` and volatility `σ`.

The visualization uses a lognormal / geometric-Brownian approximation:

```text
log(S_T / S_0) ~ Normal(
  (μ - σ²/2) T,
  σ² T
)
```

It displays:

- median path
- 50% range (25th–75th percentiles)
- 80% range (10th–90th percentiles)
- cumulative-return summaries at 1, 5 and 10 years

These bands are model-implied scenarios, not confidence intervals for the true future return and not a guarantee of investment performance.

## Current scope

Implemented:

- compact single-page interface
- CSV price import
- deterministic synthetic sample
- annualized covariance estimation
- Black–Litterman equilibrium prior
- multiple relative views
- confidence-weighted view uncertainty
- long-only fully-invested optimization
- per-asset maximum weight
- expected return / volatility / Sharpe
- allocation visualization
- efficient frontier
- 10-year probabilistic return range
- collapsible prior/posterior model detail
- fully local browser execution

Not yet implemented:

- automatic market-data download
- market-cap data for a true capitalization-weighted equilibrium prior
- NISA product eligibility database
- separate tsumitate / growth allocation limits
- current holdings and contribution-aware rebalancing
- transaction costs / taxes / FX hedging
- robust covariance estimators
- absolute views
- saved model-settings import/export

## Notes

This repository is a research / educational prototype, not investment advice. Uploaded CSV data is processed locally in the browser and is not sent anywhere by this app.
